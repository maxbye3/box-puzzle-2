# 🧩 Box Puzzle 2

A Unity-based puzzle game where players must think critically and act precisely to move boxes, solve challenges, and complete each level. Sequel to the original *Box Puzzle*, with updated visuals, improved mechanics, and new levels.

![Box Puzzle 2 Banner]()

---

## 🎮 Gameplay

Box Puzzle 2 builds on traditional Sokoban-style mechanics:
- Push boxes onto target tiles
- Solve levels using logic and spatial reasoning
- No pull mechanic — plan carefully!
- Levels become progressively more challenging

---

## 🛠️ Built With

- **Unity** 2021+ (URP)
- **C#**
- Custom level system
- Lightweight scene transitions
- Hand-authored puzzles
